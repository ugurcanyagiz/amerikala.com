# Amerikala app promotion — design assets

Single-screen app advertising direction. No feed, categories, search, login, or interactive listings on the landing page. Its only main action is opening the mobile app's store listing.

## Assets

| File | Purpose |
| --- | --- |
| `landing-desktop-concept.webp` | Desktop visual reference, 1586 × 992. Do not use the entire screenshot as the website. |
| `/public/marketing/concepts/phones-concept.webp` | Web-ready transparent derivative, 1024 × 1536, approximately 265 KB. |

Both images were generated using the built-in image generation tool. Phone screens and wordmarks inside them are illustrative concepts, not captures of the released app. Example dates, listings, text, and UI must not be presented as actual product content. Replace the phone display artwork with approved, current app screenshots for the production launch. Use the existing approved brand logo separately from the generated artwork.

## Layout and copy

- Background: warm off-white `#F8F7F4`.
- Main text: deep navy `#1E2A38`.
- Accent: muted red `#C43737`.
- Desktop: headline and store links left; phone composition right.
- Mobile: headline and store links first; phone composition below. Footer may follow below the fold on small screens.
- Keep copy as real HTML for accessibility and responsive layout.
- Eyebrow: **AMERİKA’DAKİ TÜRK TOPLULUĞU**.
- Headline: **Amerika’daki topluluğun. Artık cebinde.**
- Supporting copy: **Tanış, keşfet, paylaş. Amerikala’da bir araya gel.**
- Footer: copyright, privacy, terms, support.

Download badges visible in the desktop reference are generated placeholders. Use official store-supplied badges and verified live store URLs in implementation. Do not create a working QR code until its destination is verified. Do not imply store availability before publication.

## Generation brief

Desktop concept: premium, realistic, implementation-ready single-screen Turkish mobile app marketing page; off-white background, navy editorial typography, red final headline line, two graphite phone mockups, download badges, minimal legal footer; no web feed or additional sections.

Phone asset: isolated pair of realistic graphite phones with transparent background and soft shadows; illustrative Amerikala home and event-detail screens in navy, off-white and muted red; no external labels, floating cards or decorative objects.

## Verification

The source PNG and the phone WebP were decoded successfully and have matching 1024 × 1536 dimensions with an alpha channel. The phone WebP is approximately 86% smaller than the generated source PNG; the PNG source is retained in the image generation history. No application source files, routes, dependencies, or production branch were changed by this asset package.
